# Support

Use GitHub Issues for reproducible MDBridge bugs and feature requests. This is a volunteer early-alpha project, so response times are not guaranteed.

For account, billing, quota, or service outages, contact the relevant provider instead:

- MDBList support for MDBList accounts and API allowances
- Stremio support for Stremio accounts
- Nuvio support for Nuvio Cloud accounts
- TMDB support for TMDB API tokens

Do not post credentials or `data/config.json` in an issue.
